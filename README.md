# HER PRIME HEALTH CENTRE 🌸
### Women's Hormonal Weight Loss & Wellness Coaching by Razeeka

A premium, responsive web application for **HER PRIME HEALTH CENTRE**, dedicated to women's hormonal weight loss, PCOS/PCOD reversal, postpartum recovery, and menopause metabolism reset.

---

## 🌟 Key Features
- **Modern Responsive Design**: 3-color palette (Deep Navy Blue, Golden Yellow, Clean White) with Playfair Display & Inter typography.
- **Root-Cause Methodology**: Detailed breakdown of the 4-step coaching framework (Bio-Hormonal Audit, Low-Cortisol Movement, Hormone-Optimized Nutrition, 1-on-1 Mentorship).
- **Programs & Services**: Dedicated program details for Postpartum, Menopause & PCOS Reversal.
- **Interactive Pricing & Enrollment**: 
  - 1-Click Duration Selection Grid (`1 Mo`, `2 Mo`, `3 Mo. + 1 FREE`, `6 Mo. + 2 FREE`).
  - Dynamic price calculations and instant discount breakdowns.
- **₹99 1-on-1 Consultation Booking**: Dedicated time-slot picker with instant WhatsApp integration.
- **3D POS Thermal Receipt Machine**: Interactive animated receipt generator with live LCD status, progress bar, audio simulation, and official PDF print styling.
- **Sticky Blur Navigation**: Soft glassmorphism blur navbar across all pages.
- **Zero Emojis**: 100% vector FontAwesome iconography and clean aesthetic.
